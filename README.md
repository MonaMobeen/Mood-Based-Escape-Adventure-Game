
# 🌿 Little Escape
### Your World. Your Mood. Your Little Happiness.

**Take a break. Explore a new world. Find your little happiness.**

Little Escape is a multi-experience casual gaming platform where players can explore different worlds, express their creativity, discover hidden objects, customize spaces, and enjoy interactive adventures — all in one place.

The goal is simple: provide an engaging, accessible, and enjoyable gaming experience with something different to explore every time.

---

## ✨ About Little Escape

Little Escape brings multiple casual gaming experiences together in one interactive platform.

Instead of focusing on a single gameplay style, players can choose their own experience based on what they feel like doing.

Whether it's planting flowers, exploring peaceful environments, designing outfits, organizing rooms, solving mysteries, or running through exciting obstacles, every world offers a unique experience.

## 🎮 Game Worlds

### 🌸 1. Peaceful Garden
Create and customize your own garden.

- Plant seeds and grow flowers.
- Water plants and watch them bloom.
- Discover butterflies and birds.
- Decorate your garden with beautiful objects.
- Create your own living garden.

### 🌊 2. Peaceful World
Explore beautiful environments and enjoy interactive surroundings.

- Morning Lake
- Rainy Cabin
- Sunset Beach
- Starlight Island
- Ambient sounds and atmosphere customization.

### 👗 3. Fashion Studio
Express your creativity through fashion and character customization.

- Mix and match outfits.
- Customize clothing colors.
- Explore different fashion styles.
- Save your favorite looks.
- Create personalized fashion combinations.

### 🏝️ 4. Dream Island
Explore a beautiful island full of discoveries.

- Waterfall Cave
- Flower Forest
- Secret Beach
- Sky Islands
- Hidden objects, secret paths, and collectibles.
- Discovery Journal.

### 🛏️ 5. Room Makeover
Transform messy spaces into beautiful rooms.

- Organize clothes, books, and accessories.
- Drag and drop objects.
- Decorate and customize rooms.
- Explore different room themes.
- Compare before-and-after transformations.

### 🔎 6. Hidden Object Hunt
Test your observation skills through interactive mysteries.

- Find hidden objects.
- Solve clue-based missions.
- Explore interactive environments.
- Unlock different search modes.
- Progress through multiple levels.

### 🏃 7. Running Adventure
Enjoy an action-packed running experience.

- Jump over obstacles.
- Slide under barriers.
- Roll through challenging paths.
- Improve timing and reactions.
- Earn scores and progress through challenges.

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd little-escape
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## 🎨 Design Philosophy

Little Escape focuses on creating a visually appealing yet easy-to-use gaming experience.

Design principles:

- Simple and intuitive navigation.
- Clean and readable typography.
- Sea green, teal, aqua, turquoise, and ocean-inspired colors.
- Smooth and meaningful animations.
- Distinct visual identities for individual worlds.
- Comfortable interactions across desktop and mobile.
- Minimal visual clutter.

**Simple to use. Beautiful to explore. Rich in gameplay.**
